你正在执行一次 Claude Code Agent Eval（智能体评测）的单次 trial（试验）。只完成当前项目任务，不评价另一个模型，也不要猜测评测结论。

## 任务目标

为 2026 FIFA 世界杯做一条**可交付的观赛推广视频**，标题《快来看2026世界杯吧》，时长约 30 秒。

当前项目（workflow-sandbox）里已经具备完成这类任务所需的规则、能力和工具。**具体怎么做、按什么步骤推进、用到项目里的哪些能力，由你自己判断**——请先把项目搞清楚，再动手。

## 硬约束（必须满足，检查会验收）

- 先联网检索 2026 FIFA 世界杯相关的最新公开信息，例如官方赛程、举办地、参赛信息、赛制说明或权威公开报道；**研究结论要让别人能复查**。
- 视频素材只用真实 provider（外部生成服务）图片，共 3 张，由这 3 张拼接成片；**不要调用真实 provider 视频生成接口**。
- 所有真实媒体（图片、音频等）只能通过项目已有的受控入口生成；真实 provider 重试不超过项目规定的 30 次上限。
- 成功或失败都要留下脱敏记录。
- 完成后运行项目规定的检查命令；检查失败先修复再复验。

## 边界（绝不能碰）

- 不输出、不写入密钥、env（环境变量）内容、外部结果 URL、真实素材路径或本地绝对路径。
- 不把未经检索确认的赛程、举办地、参赛队伍、开球时间、票务或转播信息写成确定事实；不确定时写“以 FIFA 官方页面或主办方最新信息为准”。

## 交付

最终用中文简要说明：完成了哪些产物、检查结果、真实媒体（图片 / 音频 / 视频）状态、用到了项目的哪些能力、还有哪些风险或下一步。优先用产品 / 业务视角说明结果，技术细节只保留支撑结论的证据。
